## Review Focus

The five failure modes most likely to bite a player, with the test pinning each:

1. **A nav/burn activity can deadlock the flight if the player closes nothing** — `advance()` must always return; the smoke test `_play()` loop must auto-resolve every `"nav"`/`"burn"` kind (Task 4 test).
2. **Skipping every T17 activity must still let the sample design win** — worst-case dv penalty (6.37 + 6.0 m/s) added to `leg:loi` must not fail the sample run; pinned in `balance_check.py` (Task 8) and smoke test (Task 4).
3. **Skipping the thermal roll must not destroy a healthy hull** — roll skip = −2%/day × 6 transit days = −12 hull once, at the end of the return coast (Task 4 test).
4. **Stamina must refill between walks (burst budget included)** — each walk creates a fresh `Stamina`; pinned by headless test calling the walk boundaries (Task 6 test).
5. **Sample mass must be added to `run["dry"]` before `leg:return`** — `finish_explore()` adds mass; pinned by smoke test checking `dry` grew before the return burn (Task 7 test).

**Files:**

**Interfaces:**
- Produces (used by flight.gd and tests):
  - `func build_run_plan(m: Dictionary) -> Array` — steps: `{"kind":"consume","days":float,"label":String}`, `{"kind":"nav","idx":int}`, `{"kind":"burn"}`, `{"kind":"event"}`, `{"kind":"leg","id":String}`, `{"kind":"explore"}`, `{"kind":"finish"}`. Nav/burn days from `GameState.activities()` fractions × `m["days"]["transit_out"]`: nav idx0 = 0.246 d, nav idx1 = 0.984 d, burn = 1.089 d (3.0 d × 0.082/0.328/0.363).
  - `func activities() -> Dictionary` — loads `res://data/activities.json`, cached like `Stamina.cfg()`.
  - `func resolve_nav(accuracy: float) -> String` — stores into `run["nav_acc"][idx]`; returns log text.
  - `func resolve_burn(hold_fraction: float) -> String` — `r := clampf(hold_fraction, 0.0, 1.2)`; `extra := 6.0 * (1.0 - avg(run["nav_acc"]))`; `dv_applied := (6.37 + extra) * r` m/s; consumes propellant via rocket equation (`m_i = dry+prop`, `ve = isp*g0`, `need = m_i*(1-exp(-dv_applied/ve))`); `run["dv_penalty_m_s"] = (1.0 - r) * (6.37 + extra)`; `run["burn_done"] = true`; returns log text with "Real basis: Apollo 11 (20.9 ft/s)" where the number shown is nominal.
  - `func set_thermal_roll(on: bool) -> void` — `run["roll_on"] = on`.
  - `func set_exercise_hours(h: int) -> void` — `run["exercise_hours"] = clampi(h, 0, 2)`.
  - `func stamina_capacity_mult() -> float` — 1.0 if `run["exercise_hours"] >= 2` else 0.9 (game).
  - `func resolve_roll_hull_damage() -> void` — if `run["roll_on"] == false`: `run["hull"] -= 2.0 * (transit_out + transit_back)`; applied exactly once after the return-coast consume.
  - `advance()` returns `{"kind":"nav"|"burn","idx":n}` when the plan hits those steps, and applies `dv_penalty_m_s` inside `_burn()` (added to the leg dv once, then reset to 0.0).
  - `run` new fields: `"plan"`, `"nav_acc"`, `"burn_done"`, `"dv_penalty_m_s"`, `"roll_on"` (default true), `"exercise_hours"` (default 2), `"morale"` (int, from `GameState.harvest_count`), `"walks_log"` (Array).
  - Save: `SAVE_VERSION = 5`; new key `"harvest"` (int, default 0) → `harvest_count` (incremented in `harvest_plot()`); old saves get 0.
