LAST LAUNCH v0.4.1 - WEB BUILD
==============================

วิธีเล่น (สำคัญ)
----------------
ดับเบิลคลิก PLAY_WEB.bat
โปรแกรมจะเปิด localhost:8000 และเปิดเบราว์เซอร์ให้อัตโนมัติ
เล่นเสร็จแล้วปิดหน้าต่างดำ (server) ได้เลย

ห้ามดับเบิลคลิก index.html โดยตรง
เพราะเบราว์เซอร์ไม่อนุญาตให้โหลด .pck / .wasm จาก file://
(จะเห็นหน้าจอค้างหรือ error ใน Console)

เครื่องเก่า / การ์ดจอไม่รองรับ
-----------------------------
เวอร์ชันนี้เหมาะกับเครื่องที่เปิด exe แล้วขึ้น
"Unable to initialize video driver" เพราะเบราว์เซอร์มี software WebGL
แนะนำ Chrome หรือ Edge รุ่นใหม่ และเปิด hardware acceleration ถ้าทำได้

ถ้า PLAY_WEB.bat เปิด port ไม่ได้
--------------------------------
มี Python อยู่แล้วหรือไม่ก็ได้ - สคริปต์มี server ในตัว
ถ้า port 8000-8010 ถูกใช้อยู่ ให้ปิดโปรแกรมอื่นแล้วลองใหม่

ข้อมูลเกม
---------
- Save ของเวอร์ชันเว็บอยู่ใน browser storage ของเบราว์เซอร์นั้น
- เวอร์ชันเว็บกับ Windows ใช้ save คนละที่กัน (แยกกัน)
